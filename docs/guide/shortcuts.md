# Shortcuts & appearance

## Shortcuts

| Keys | Action |
|---|---|
| ⌘N / ⌘⇧N | New task (focus composer) / new note |
| ⌘1 / ⌘2 / ⌘3 / ⌘4 / ⌘, | Tasks / Focus / Notes / Blocks / Settings |
| ⌘⇧F | Start/pause focus timer |
| Enter / Esc | Add or save / cancel edit |
| ⌘⇧T | Toggle light/dark |
| ⌘W / ⌘Q | Close window (app stays in Dock) / Quit |

Editor keys: [Notes → Block editor](notes.md#block-editor).

## Appearance

Settings → Appearance switches light and dark. **Ambient motion** turns off the drifting glow
and pulsing indicators (saves battery); they also pause while the window is in the background.
macOS "Reduce motion" is honoured by every animation.

The palette lives in `themes/buffer.json` ([development](../development.md#themes)).
